## 📖 Sobre o Projeto  
O InspectCar - Martelinho de Ouro foi desenvolvido para facilitar o dia a dia dos profissionais de funilaria e pintura.
Com ele, o Martelinho de Ouro pode registrar as avarias diretamente em um croqui do veículo, criar orçamentos detalhados e apresentar os serviços de forma profissional aos clientes.

A plataforma tem como objetivo organizar, agilizar e padronizar os atendimentos, oferecendo uma experiência moderna e intuitiva tanto para o profissional quanto para o cliente.

Com o InspectCar, o processo de avaliação e orçamento se torna mais rápido, visual e confiável, permitindo que o cliente entenda com clareza onde estão os danos e o valor do serviço.
